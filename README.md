# MC Link

我的世界联机工具 — 无需公网 IP、无需端口映射、无需内网穿透即可远程联机。

> **架构状态**
> 1. 联机核心已从"自建中继转发"迁移为基于**折跃门协议（WGP）**的 P2P 直连。
>    旧中继实现（`mc-link-relay/`、`mc-link-chat/`）已停止维护并移出主分支，
>    源码保留在 `archive/legacy-relay` 分支与 `legacy-relay-stack-v0.4.0` tag。
> 2. 认证实现已整体移除（客户端登录 / Token 校验 / 桌面登录轮询，以及 `central-server/`）。
>    现阶段客户端不含登录功能；后续鉴权将由 **OpenXigoID** 与 **Prism Auth** 承担。
>    相关源码保留在 `legacy-auth-central-v0.4.0` tag。
> 3. **联机核心已暂时断开**：`wgp-core` 依赖与其 Tauri 命令已移除，项目可独立构建，
>    不再需要仓库外的 `mc-link-core`。重新接入参考 `legacy-wgp-p2p-v0.4.0` tag。
>    过渡期点击"开始联机"会失败，联机能力将在 UI 重构与插件系统落地后重新接入。

## 架构

```
MC Link 客户端 (Tauri 2)
  ├── 设置中心 / 个性化 / 窗口与托盘
  ├── 陶瓦适配器集成 (adapter，本地 exe)
  └── 资源与远程页面 (assets-server 提供字体 / 图标 / 页面片段)

[暂时断开] 折跃门协议 P2P (wgp-core) —— 待 UI 重构与插件系统完成后重新接入
```

- **客户端** (`src-tauri` + `src`)：Tauri 2 桌面应用
- **资源服务器** (`assets-server`)：字体 / 图标 / 远程页面片段的本地开发服务

## 快速开始

### 下载客户端

从 [Releases](https://github.com/DogerMMC/mc-link/releases) 下载最新版本 `mc-link-v0.x.x.exe`，直接运行即可。

### 使用

> 联机功能当前**不可用**（WGP 核心已暂时断开，见上方架构状态第 3 条）。
> 现有可用能力：设置中心、个性化主题、窗口与托盘、陶瓦适配器集成。

1. **房主**（重新接入联机核心后可用）：启动 MC Link → 创建房间 → 开始联机
2. **成员**（同上）：启动 MC Link → 输入房间信息 → 开始联机 → 在 Minecraft 内连接显示的地址

## 技术栈

- **客户端**: Tauri 2 + Vue 3 + TypeScript + Rust
- **P2P 核心**: 折跃门协议（`wgp-core`）—— 当前已断开，待重新接入
