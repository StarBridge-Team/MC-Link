# MC Link 项目总结 & 新项目（AviovaUI + Rust）交接文档

> 本文档总结 MC Link 项目（v0.4.0）的**非联机 P2P 核心**部分，并为后续基于**C# AviovaUI 前端 + Rust 后端**的全新项目提供交接参考。旧联机网络协议/中继隧道代码已废弃，新项目采用\*\*折跃门协议（WGP）\*\*作为 P2P 核心替代。

## 一、MC Link 项目定位与整体架构

### 1.1 项目目标

MC Link 是一款桌面端我的世界联机辅助工具，提供：

* 房主扫描本机 Minecraft 局域网联机，将其暴露至中继服务器（旧联机核心，已废弃）

* 成员通过中继服务器连入房主的 MC 局域网（旧联机核心，已废弃）

* **新联机核心**：基于\*\*折跃门协议（WGP）\*\*的纯 P2P 直连架构，无中继、端到端加密

* **非联机核心功能**：账号体系、个性化主题/背景/动效、托盘与窗口管理、设置中心等

### 2.3 状态管理

**未使用 Pinia/Vuex**，采用三套简单方案：

| 方案                                | 适用       | 示例                               |
| --------------------------------- | -------- | -------------------------------- |
| 模块级 reactive ref                  | 全局单例状态   | Toast、navigateTo                 |
| `provide` / `inject`              | 跨层级共享上下文 | `provide('navigateTo', fn)`      |
| `localStorage` / `sessionStorage` | 持久化      | window\_state、player\_name、token |

**关键约定**：

* 持久化用 `lib/storage.ts`（**已封装** try/catch 安全的 `safeGet`/`safeSet`/`strGet`/`strSet`）

* 临时态用 `lib/session.ts`（自动加 `mc_session_` 前缀）

* 直接 `localStorage.xxx` 调用是**反模式**，新项目要杜绝

### 2.5 路由 / 页面切换

**无 vue-router**，采用 **"状态驱动 + KeepAlive 缓存"** 模式：

```vue
<!-- App.vue -->
<KeepAlive>
  <Transition name="page-fade" mode="out-in">
    <HomePage v-if="activeIcon === 'home'" key="home" .../>
    <ConnectPage v-else-if="activeIcon === 'connect'" key="connect" .../>
    <SettingPage v-else-if="activeIcon === 'setting'" key="setting" .../>
  </Transition>
</KeepAlive>
```

`activeIcon` (`home`/`connect`/`relay`/`setting`) 和 `activeText`（设置子页）由根组件管理，通过 `provide('navigateTo', fn)` 注入。

**优点**：实现简单、KeepAlive 缓存组件状态。**缺点**：所有页面必须在 App.vue 中显式 import；不支持按需加载/深链。

> 新项目可考虑改用 vue-router，但当前这套"伪路由"已能稳定工作。

### 2.6 与后端通信

**所有与 Rust 后端的交互都通过** **`invoke()`** **调用 Tauri command**：

```ts
// src/lib/api/settings.ts
import { invoke } from "@tauri-apps/api/core";
export async function getSetting(section: string) {
  return invoke<string>("get_setting", { section });
}
```

约定：

* 参数命名遵循 Rust `#[tauri::command(rename_all = "snake_case")]`，即 JS 端用 snake\_case

* 返回值由 Rust 端 `serde::Serialize` 自动转为 JS 对象，**前端不要再** **`JSON.parse()`**

* 类型集中在 `src/lib/api/types.ts` 维护

**API 文件按业务领域拆分**（不要堆在一个文件）：

* `app.ts`（版本、init、prepare、IP）

* `settings.ts`（设置读写、个性化、背景、窗口特效）

* `account.ts`（登录、验证、用户信息、头像）

* `adapter.ts`（陶瓦联机适配器，**但后端实际可继续保留**）

* `game.ts`（联机相关，**新项目无需迁移**）

* `relay.ts`（客户端中继，**新项目无需迁移**）

* `revamp.ts`（联机相关，**新项目无需迁移**）

* `types.ts`（共享 TS 类型）

### 2.7 资源缓存与离线

`src/lib/resourceCache.ts` 缓存两样东西到 `localStorage`：

| Key                 | 内容                                   | 来源                                    |
| ------------------- | ------------------------------------ | ------------------------------------- |
| `resource_cache_v1` | Google Fonts CSS（Poppins）            | 预下载                                   |
| `bi_css_v1`         | Bootstrap Icons CSS（含字体 data-uri 嵌入） | 后端 `prepare_app` 命令下载并 base64 内嵌字体后返回 |

**前端冷启动流程**（在 `App.vue` `onMounted` 中）：

```
1. 读 cached 个性化（轻量、无网络）→ apply 主题
2. tryInjectCachedIcons()              # 立刻注入缓存避免 FOUC
3. initApp() (Rust 轻量命令)            # 个性化 + 版本 + 默认窗口特效
4. 应用主题、解析背景文件 URL、设置窗口特效
5. adapterStartupInit()                # 适配器（陶瓦）
6. restoreWindowState()                # 读 localStorage 恢复位置/大小
7. appReady = true (SplashScreen 淡出)
8. prepareApp() 后台下载缺失资源        # 含中继列表 + BI CSS 等
```

| 路径                                              | 内容                                               |

### 3.5 Tauri Command 规范

**关键约定**（必须遵守）：

1. **snake\_case 参数命名**：所有参数用 `#[tauri::command(rename_all = "snake_case")]`，前端传 snake\_case
2. **状态注入**：`tauri::State<'_, AppState>` / `tauri::State<'_, DataDir>` / `tauri::Window` / `tauri::AppHandle`
3. **错误处理**：返回 `Result<T, String>`，错误用中文/英文描述（前端原样显示给用户）
4. **耗时操作**：`async fn` + `tokio::spawn` 异步执行
5. **日志/事件**：通过 `window.emit("event-name", payload)` 推送实时日志给前端
6. **阻塞 HTTP**：账号/中央服务器 HTTP 请求统一走 `reqwest::blocking`，单例 `OnceLock<Client>` 复用
7. **锁中毒**：用 `utils::lock_or_recover(&mutex, "context")` 强制恢复 + 日志
8. **后台线程 panic**：`catch_unwind(AssertUnwindSafe(|| ...))` 捕获并 emit 错误

### 3.6 窗口与平台特性

**`lib.rs`** **中实现**：

* **Win11 Mica / Win10 Acrylic**：`apply_mica_backdrop_typed(window, 2|3|0)` 通过 `DwmSetWindowAttribute(hwnd, 38, ...)` 设置

* **macOS Vibrancy**：通过 objc 运行时创建 `NSVisualEffectView` 注入 `NSVisualEffectMaterialHUDWindow` 材质

* **Linux**：无原生支持，窗口特效只能依赖 compositor（Mica 等不可用）

* **窗口拖拽**：HTML 端用 `data-tauri-drag-region` + Rust `drag_window` command（双协议：X11 用前者，Wayland 必须用后者）

* **托盘**：左键切换显隐、右键菜单（通过 `tray::setup_tray`）

* **全局快捷键**：`Alt+M` + `Alt+O` 双键唤醒主窗口（顺序按下 1s 内有效）

## 四、折跃门协议（WGP）核心速览

> 完整规范参考 `e:/Work Files/Code/Rust/mc-link-core/docs/08-折跃门协议技术规范.md`。本节仅提炼新项目需要关注的要点。

### 4.1 设计原则

* **纯 P2P 直连**：业务数据不经过任何第三方服务器，服务器只负责信令协调。

* **协议与业务解耦**：WGP 不感知上层业务内容，MC 联机只是 `GameTcp` / `GameUdp` 两种 `AppType` 之一。

* **三层 Fallback**：双栈直连（L1）→ 协议翻译隧道（L2）→ 编码兜底（L3）。

* **端到端加密**：ECDH(X25519) + HKDF-SHA256 + AES-256-GCM，信令服务器无法解密。

### 4.2 六层模型

```
L6 应用层              业务数据 (MC Java/基岩版等)
L5 应用适配层          AppType 声明 + 传输特征映射
L4 折跃门层            加密 / 打洞 / 隧道 / 保活 / 切换 / 定时
L3 传输适配层          TCP/UDP 自适应 + 场景化切换
L2 传输层              TCP / UDP
L1 网络层              IPv4 / IPv6 双栈 (Happy Eyeballs)
```

### 4.3 关键算法

| 算法                  | 作用                               | 新项目需要关注                            |
| ------------------- | -------------------------------- | ---------------------------------- |
| **Warp Punch**      | NAT 穿透打洞，含步长学习 + 三波探测            | 通过 `wgp-core` API 调用，无需重写          |
| **DSTE**            | 双栈直连 → 隧道(Teredo/6to4/自建) → 编码兜底 | 隧道全在本地，不引入中继                       |
| **Warp Crypto**     | ECDH + AES-256-GCM 加密            | 自动协商密钥                             |
| **Warp Keep-Alive** | 动态心跳 + 步长校准 + 心跳合并               | 上层业务心跳可合并                          |
| **Warp Switch**     | TCP/UDP 按 AppType 和运行阶段切换        | MC Java 用 `GameTcp`，基岩版用 `GameUdp` |
| **Warp Timer**      | 高精度 / 相对定时器双模切换                  | 关键打洞窗口自动切高精度                       |

### 4.4 AppType 映射

| AppType         | 值    | 首选协议 | 典型场景               |
| --------------- | ---- | ---- | ------------------ |
| `GameTcp`       | 0x01 | TCP  | MC Java 版          |
| `GameUdp`       | 0x02 | UDP  | MC 基岩版 (RakNet 直通) |
| `RemoteDesktop` | 0x03 | TCP  | RDP/VNC            |
| `FileTransfer`  | 0x05 | TCP  | 文件传输               |
| `VoIP`          | 0x09 | UDP  | 语音通话               |
| `Stream`        | 0x0A | UDP  | 流媒体                |
| `CustomTcp`     | 0x0B | TCP  | 自定义 TCP 业务         |
| `CustomUdp`     | 0x0C | UDP  | 自定义 UDP 业务         |

### 4.5 服务器角色

| 服务器        | 数量           | 职责                |
| ---------- | ------------ | ----------------- |
| 信令协调服务器    | 1（单节点无状态）    | 密钥交换、打洞协调、状态管理    |
| STUN 探测服务器 | ≥ 3（不同 IP 段） | NAT 探测、防火墙探测、端口采集 |

### 7.4 IPC 接口约定（C# ↔ Rust）

前端 invoke 命名（snake\_case）：

| 域      | C# 调用样例                                                                                                                           |
| ------ | --------------------------------------------------------------------------------------------------------------------------------- |
| 设置     | `await Tauri.InvokeAsync<Personalization>("get_personalization")` / `Tauri.InvokeAsync("save_personalization", new { settings })` |
| 账号     | `Tauri.InvokeAsync<AccountResponse>("account_login", new { username, password_hashed })`                                          |
| 窗口     | `Tauri.InvokeAsync("minimize_window")` / `Tauri.InvokeAsync("set_window_effect", new { effect })`                                 |
| 主题     | `Tauri.InvokeAsync<string>("get_default_effect")`                                                                                 |
| P2P（新） | `Tauri.InvokeAsync("wgp_start_host", new { room, app_type })` / `Tauri.InvokeAsync("wgp_join_room", new { room })` 等              |

事件订阅（C# 端用 `Tauri.Listen`）：

```csharp
await Tauri.Listen<WgpStatus>("wgp-status-update", e => ViewModel.Status = e.Payload);
await Tauri.Listen<ulong>("wgp-latency-update", e => ViewModel.Latency = e.Payload);
await Tauri.Listen<string>("wgp-log", e => AppendLog(e.Payload));
await Tauri.Listen<string>("app-log", e => AppendLog(e.Payload));
await Tauri.Listen<ResizePayload>("tray-resize", e => ResizeTray(e.Payload));
```

## 八、迁移注意事项 & 已知坑

| 主题                          | 说明                                                                                                                                        |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **设计 token 翻译**             | `design-system.css` 的 CSS 变量需翻译为 AviovaUI `ResourceDictionary` 资源（圆角 / 间距 / 字号 / 颜色 / 动效时长）                                               |
| **WinUI Fluent 主题切换**       | `ElementTheme` + `RequestedTheme` 事件，不要手动改 Background 颜色（破坏 Mica 效果）                                                                      |
| **Mica 效果**                 | 主窗口用 `Window.SystemBackdrop = MicaBackdrop`；仅 Win11 (19041+) 有效，Win10 自动降级为 `Acrylic`                                                     |
| **FA 字体打包**                 | FA 字体（`fa-solid-900.ttf` 等）作为 `Content`/`Resource` 嵌入；C# 端用 `FontFamily="pack://application:,,,/Resources/#Font Awesome 6 Free Solid"` 加载 |
| **FA 图标枚举**                 | 在 C# 端定义 `FaSolid.House` 之类的枚举，避免硬编码 Unicode 字符；用 `IValueConverter` 转为 FontFamily + Unicode                                               |
| **Reveal Highlight**        | 鼠标悬停高光在深色 Mica 背景下表现较好；浅色 Acrylic 下需调整 `SystemControlHighlightListLowBrush` 透明度                                                           |
| **Frame 缓存（KeepAlive 等价物）** | AviovaUI 用 `Frame.Navigate` + 缓存页实例，避免每次重新创建 ViewModel；状态保留在 VM 中                                                                         |
| **无边框窗口**                   | 若用 `ExtendsContentIntoTitleBar = true` + `AppTitleBar`，Rust 端 `drag_window` 仍可正常工作                                                        |
| **assetProtocol**           | 新项目若仍用本地视频/图片背景，必须开启 `assetProtocol.enable: true` + `scope: ["**"]`                                                                       |
| **数据目录**                    | 沿用 `app_data_dir()`，**禁止** `Environment.CurrentDirectory`（Linux AppImage 只读）                                                              |
| **托盘 + 单实例**                | 沿用 `tray-icon` + 显隐逻辑；新项目若用单实例，注意 `app.exit()` 行为                                                                                         |
| **错误处理**                    | Rust 端 `Result<T, String>` 错误消息用 `format!` 中文描述（前端原样显示）                                                                                   |
| **锁中毒**                     | 沿用 `lock_or_recover()` 工具                                                                                                                 |
| **密码哈希**                    | 前端用 `crypto.subtle.digest('SHA-256')`（若仍用 WebView 登录页）；C# 端用 `SHA256.HashData()` 等价实现（Hex 小写）                                             |
| **FA 字体加载（取代 BS 内嵌）**       | 取代 MC Link 的 `download_bootstrap_icons()`：FA 字体作为应用资源打包，启动时无需下载                                                                           |
| **配置 section 文件化**          | 沿用 `Setting/*.yml` + 通用 `get_setting/save_setting`；C# 端用 `YamlDotNet` 序列化                                                                 |
| **WindowState 持久化**         | 建议由 C# 端用 `ApplicationData.Current.LocalSettings` 存窗口位置/大小（key: `window_state`），比 localStorage 更稳                                         |
| **WGP 协议规范**                | 必读 `e:/Work Files/Code/Rust/mc-link-core/docs/08-折跃门协议技术规范.md`                                                                            |
| **WGP 代码入口**                | `e:/Work Files/Code/Rust/mc-link-core/wgp-core/src/lib.rs` — 协议核心 crate 入口                                                                |
| **旧 P2P 代码不可复用**            | `protocol.rs` / `lan.rs` / `host.rs` / `client.rs` 等全部废弃，WGP 替代                                                                           |
| **无中继设计**                   | WGP 业务数据不经过第三方服务器，服务器只做信令/STUN；不要在新项目中复用 `mc-link-relay` 思路                                                                               |
| **AppType 选择**              | MC Java 版用 `GameTcp` (0x01)，基岩版用 `GameUdp` (0x02)                                                                                         |
